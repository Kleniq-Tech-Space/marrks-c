# MARRKS C

Premium building-materials showroom frontend prototype.

## Stack

- Next.js App Router
- React
- TypeScript
- CSS design tokens
- Framer Motion ready
- Mock product catalogue

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Current scope

This phase is intentionally frontend-only. Reservation, authentication, database, admin dashboard, notifications, PDF/QR generation and distributor workflows will be added after the client approves the visual direction.
